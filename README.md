# 卜算 - 彩票娱乐软件

一个融合了现代机器学习与传统易学文化的彩票娱乐应用程序。**本软件仅供娱乐研究之用，不构成任何投注建议，彩票本质为随机事件，理性娱乐，拒绝赌博。**

## 🎴 软件理念

**卜算 - 彩票娱乐软件** 旨在为彩票爱好者提供多元化的号码分析与生成方式，结合：
- 机器学习预测模型（GBDT、LightGBM、CatBoost、XGBoost、集成模型）
- 传统易学算法（紫微斗数、梅花易数）
- 统计学选号参考

让娱乐更有趣味，让分析更有深度。

## ✨ 主要功能

### 1. 预测模式
- **单式预测**：生成单组号码
- **复式预测**：支持自定义红球/蓝球选号范围（如大乐透 7红3蓝）
- **胆拖预测**：胆码固定，拖码组合，红蓝均支持

### 2. 预测模型
- **机器学习模型**（位于「预测」标签页）：
  - 梯度提升树(GBDT)
  - LightGBM
  - CatBoost
  - XGBoost
  - 集成模型(Ensemble)
  - 随机森林
  - 期望值模型
- **传统易学模型**（独立标签页，详见下方第5节）：
  - 紫微斗数：独立排盘标签页，3组号码3种宫位视角
  - 梅花易数：独立起卦标签页，3组号码3种取象路径

### 3. 数据分析
- 历史开奖数据统计
- 热点/冷号分析
- 遗漏期数预警
- 奇偶比、大中小号分布
- 和值区间分析
- AC值参考
- **选号参考建议**：将统计指标翻译成人话，提供直观的选号提示

### 4. 历史回测
- 滚动窗口回测
- 不同模型性能对比
- 置信度校准分析
- 预测记录存档与核验

### 5. 传统易学独立标签页

#### 紫微斗数标签页
- 输入姓名、性别、出生年月日时、出生城市（用于真太阳时修正）
- 系统自动排盘，生成 **3组号码**，每组来自不同宫位视角：
  - 第1组：正财视角（财帛宫主星 + 年干四化）
  - 第2组：偏财视角（官禄宫 + 迁移宫 + 福德宫）
  - 第3组：本命视角（命宫 + 身宫 + 大限宫）
- 每组附带推演过程说明

#### 梅花易数标签页
- 输入起卦时间（年月日时分）
- **默认时间起卦**，无需输入数字
- 可勾选「使用直觉数字起卦」，勾选后三个数字输入框变为可编辑，用于输入直觉感应数字
- 生成 **3组号码**，每组来自不同取象路径：
  - 第1组：本卦主象（时间起卦）
  - 第2组：互卦过程（体用五行生克）
  - 第3组：外应灵数（数字起卦）
- 每组附带卦象解读

### 6. 投注分析
- **Kelly Criterion（凯利公式）**：科学计算最优投注比例
- 期望值分析
- 不同奖池规模下的盈亏评估

### 7. 界面特色
- 古风主题（卜算古风）：墨黑/朱砂/宣纸黄/青铜配色
- 现代简约主题
- 全局字体统一
- 预测结果加粗放大显示
- 智能模型-模式联动：不支持复式/胆拖的模型自动禁用对应选项
- **所有结果页支持一键复制和打印**：每个标签页底部有「复制结果」「打印结果」按钮
  - 复制：提取当前页结果文本到系统剪贴板
  - 打印：弹出系统打印对话框，带标题+时间戳格式化打印

## 🚀 快速开始

### 运行软件
```bash
python main.py app
```

### 命令行操作
```bash
python main.py fetch ssq       # 获取双色球数据
python main.py fetch dlt       # 获取大乐透数据
python main.py train ssq --model lightgbm
python main.py predict ssq --model ensemble
python main.py backtest ssq --model gbdt
python main.py records --verify
```
